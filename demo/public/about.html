About kiro-heal

A drop-in CLI that watches your repository, runs Kane browser tests, and automatically repairs regressions using isolated code generation.

Architecture

The scanner discovers public routes, the runner executes Kane CLI in --agent --headless mode, the parser consumes NDJSON step events, and the healer rewrites failing source files until verification passes.

Designed for demos

This page exists so navigation smoke tests can verify routing without a full framework. The UI is static HTML, CSS, and vanilla JavaScript — fast, readable, and easy to audit.
